# Bundled fonts

## DroidSansFallbackFull.ttf
Droid Sans Fallback — glyph coverage for CJK (Chinese / Japanese / Korean),
used as an egui fallback font so those scripts render in the UI (egui's default
fonts cover only Latin + Cyrillic).
